# Experimental Voice Pipeline

This folder contains archived experimental modules from the initial multimodal version of BOLVEDA.

These modules explored:
- Speech-to-Text (Whisper)
- Text-to-Speech
- Voice orchestration
- Audio interaction workflows

The project was later refactored into a streamlined text-first RAG platform focused on:
- document-grounded retrieval
- conversational AI
- lower latency
- simpler deployment
- improved maintainability

These files are preserved for experimentation and architectural reference.
